# IncrediBro Games v12

A clean static studio website based on the supplied visual blueprint, with a living Three.js background.

- HTML/CSS content stays conventional and accessible.
- Three.js is visual atmosphere only: neon room, ambient cabinets, particles, and subtle mouse/scroll parallax.
- The supplied `cabinet.glb` is used for the hero cabinet.
- Game cards and navigation remain normal HTML links.
- WebGL failure gracefully leaves the static page usable.

Open `index.html` locally or deploy the folder to GitHub Pages.
